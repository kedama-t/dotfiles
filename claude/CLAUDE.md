# 言語・ツールの既定

- 新規 JavaScript/TypeScript プロジェクトでは、特別な理由がない限り `npm` ではなく `bun` を使う。
- JavaScript/TypeScript の Linter/Formatter には `Biome` を使う。
- 新規 Python プロジェクトでは、特別な理由がない限り `uv` を使う。
- 既存プロジェクトに package manager / runtime / lockfile / CI 設定がある場合は、
  上記より既存プロジェクトの方針を優先する。

コーディングタスクの進め方は `coding-principles` skill に定めている。
